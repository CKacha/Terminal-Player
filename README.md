# Terminal-Player

Application to take videos and let them be played in terminal in black &amp; white

(WINDOWS ONLY FOR NOW, at least until I can figure out an .exe release :p )

This is going to be scuff but oh well

# HOW TO RUN:

Download the repo for yourself

Go in vscode/your code editor and open up to the project folder

cd Terminal-player 
py -m pip install -r requirements.txt
add or you can convert one of the videos already in the videos folder :>
then run py.main.py!

Follow the instructions after & you should be good to go!
